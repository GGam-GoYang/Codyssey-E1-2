## 실행 결과 발췌

```text
최종 점수 : 6점
축하합니다! 최고 점수 6점을 달성했습니다!
```

```text
점수를 확인합니다.
당신의 최고 점수는 6점 입니다!
```

```text
데이터 저장에 성공했습니다!
프로그램을 종료합니다.
```
